## 2. 발견된 결함과 소규모 수정

### UX-09-01 — 스킵 링크의 실제 키보드 초점 전달

- 기존 `space-shell.tsx`의 `본문으로 바로가기`는 `href="#main-content"`로 스크롤할 수 있지만, **키보드 초점이 비탭 가능 main으로 전달되는지 기존 검사는 확인하지 않았음**. `navigation.spec.ts`의 스킵 링크 검사는 해시와 가시성만 확인.
- `SkipToMain` Client island를 최소 크기로 신설. 링크에서 Enter/클릭 시 기존 `main#main-content`에 `tabIndex=-1`을 부여하고 `focus({ preventScroll: true })`로 이동; 브라우저 해시 이동은 그대로 유지. 정상 Tab 순서에 새 초점 정류장이 추가되지 않음.
- **JS 사용 불가** 상태에서도 원래의 `#main-content` HTML 앵커는 남김. 신규 테스트는 실제 `document.activeElement.id`와 이어지는 Tab이 헤더가 아니라 **본문 안의 첫 컨트롤**로 이동하는지 점검.
- 수정 파일: `src/components/skip-to-main.tsx`, `src/components/space-shell.tsx`.

### UX-09-02 — 커뮤니티 검색/작성 입력창 테두리 대비

- 기존 `community-demo.css` 검색·선택·입력·textarea 테두리는 **#aaa6a8 vs #ffffff = 2.41:1**. 비텍스트 UI의 기본 경계 대비 목표(3:1)에 미달.
- **#6f6a70 vs #ffffff = 5.29:1**로 조정. 나머지 아이보리·블루그레이/크림·베리 색상, 폰트, 카드 비율·간격, 44px 입력 높이 유지. 두 역할의 4개 필드군에서 브라우저 computed style 대비를 동적으로 계산하도록 테스트 추가.
- 수정 파일: `src/app/community-demo.css`.

## 4. 후속 잔여 위험·우선순위

- **G1-09 이후에도 별도 실기기 QA 필요:** iOS Safari(주소창/키보드/하단 safe-area), Android Chrome(글자 확대·터치), 실제 VoiceOver/TalkBack 읽기 순서·초점·라디오 안내. 실행되지 않았으므로 명시적으로 **미검증**.
- **향후 시각 감리:** 실제 모바일 스크린샷과 수동 육안으로 이미지 크롭·문단 리듬·상단 네비·스크롤 오브젝트 충돌/긴 문장 확인. 자동 axe·DOM 테스트는 이를 대체하지 않음.
- **G2-01~03 전체 HOLD 유지:** 미성년자 법률/동의/연령 검증/신고·운영/Security/Auth/RLS 승인 전 실제 쓰기·집계·권한·배포 금지.
- 다음 단계는 G1-10을 자동으로 개발하는 것이 아니라 **G1 전체 Gate 최종 체크 + G2 정책/보안 설계 착수 여부를 사용자와 구분해 결정**하는 것입니다. 사용자 버튼 요청 시 G1-10 범위를 '안전한 시연 품질 유지와 실기기 QA 준비'로만 제한해야 합니다.
