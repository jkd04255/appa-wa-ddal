## 남은 범위 / 제한

- Chromium의 모바일 뷰포트 시뮬레이션은 **실제 iPhone Safari·Android 실기기 테스트가 아님**. 실기기·수동 스크린리더/시각 디자인 확인은 후속 별도 QA로 남김.
- 아빠·딸 4탭 내비게이션은 G1-03, 아빠·딸 실제 홈은 G1-04·G1-05에서 순차 구현.
- 역할 버튼은 접근 권한 증명이 아님. 실제 청소년 커뮤니티는 G2 안전·운영·법률 검토 전 금지.
