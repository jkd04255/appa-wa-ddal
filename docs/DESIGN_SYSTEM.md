## 1. 브랜드 콘셉트와 의도

**한 브랜드, 다른 편집 리듬.** 공통 디자인 문법을 사용하되 아빠 공간은 ‘차분한 설명형 매거진’, 딸 공간은 ‘취향과 사진 중심 발견형 매거진’으로 구분한다. 단순한 핑크/블루 성별 고정관념은 쓰지 않는다.

- 메인: **같은 집, 조금 다른 세상.**
- 부제: **우리가 몰랐던 서로의 이야기.**
- 핵심 감정: 존중·호기심·실용성. ‘딸을 이해해야만 한다’는 강요, 아이를 관찰·추적하는 듯한 문구 금지.
- 사용자가 5초 안에 알 것: 현재 어느 공간인지 / 무엇을 볼 수 있는지 / 다음 행동.
- 한 화면은 **히어로 1개, 짧은 보조 카드, 명료한 이동**에 집중. 팝업·움직이는 배너·과도한 CTA 제거.
- 역할 선택은 단지 화면 탐색용. 실제 나이·가족관계·글쓰기 권한의 인증으로 표시하지 않는다.
- **최초 방문은 역할 선택**, 재방문은 마지막 선택 공간을 기본 화면으로 제공한다(v2.0 유지). 사용자에게는 어느 화면에서든 명시적으로 랜딩에 돌아와 역할을 다시 선택할 수 있는 동선을 제공한다. 저장·분기 방식은 G0-04에서 정의하며 해당 저장값은 권한 근거가 아니다.

### 문서상 색상 대비 계산

WCAG 2.x 상대휘도 기반 대비비(반올림). **이미지 위 텍스트·동적 상태의 렌더링 대비는 계산 결과에 포함되지 않으며 G1 실화면 검증 필수**.

| 조합 | 대비비 | 본문 4.5:1 충족 |
| --- | ---: | --- |
| #252A2F / #F5F2EB | 12.95:1 | 충족 |
| #252A2F / #FAF8F4 | 13.65:1 | 충족 |
| #525B62 / #F5F2EB | 6.20:1 | 충족 |
| #525B62 / #FAF8F4 | 6.53:1 | 충족 |
| #FFFFFF / #275467 | 8.23:1 | 충족 |
| #FFFFFF / #774A61 | 7.15:1 | 충족 |
| #275467 / #E7EEF0 | 7.01:1 | 충족 |
| #774A61 / #F2E9EE | 6.02:1 | 충족 |

- 경계선은 배경과 대비가 낮으므로 **테두리만으로 클릭 가능/선택 상태를 표현하지 않는다**.
- 이미지 위 제목은 원칙적으로 피하고 **이미지 아래 단색 텍스트 패널**을 사용한다. 꼭 겹칠 경우 이미지별 대비 측정 후 충분히 불투명한 스크림과 대체 대비를 적용한다.
- 색상만으로 만료·시연·선택·오류를 구분하지 않고 텍스트와 함께 표시한다.

## 3. 한글 타이포그래피

권장 기본 스택: system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif.

외부 폰트(예: Pretendard Variable)는 라이선스·셀프호스팅·성능 검토 후 G0-04/G1에서 별도 결정하며 이 단계에서는 폰트 파일을 추가하지 않는다.

| 토큰 | 모바일 | 768px 이상 | 활용 |
| --- | --- | --- | --- |
| display | 36px / 줄간격 1.18 / 굵기 700~800 | 52px / 1.16 | 랜딩 카피 |
| h1 | 30px / 1.25 / 700 | 40px / 1.2 | 홈·상세 제목 |
| h2 | 23px / 1.34 / 700 | 28px / 1.3 | 섹션 |
| h3 | 19px / 1.38 / 650~700 | 21px / 1.35 | 카드 |
| body-dad | **17px / 1.65 / 400** | 18px / 1.65 | 아빠 본문 |
| body-daughter | **16px / 1.6 / 400** | 17px / 1.6 | 딸 본문 |
| body-subtle | 15px / 1.55 / 400 | 15px / 1.55 | 부가 설명 |
| meta | 13~14px / 1.45 / 500 | 14px / 1.45 | 출처·데모 |
| nav | 12~13px / 1.25 / 600 | 13px / 1.25 | 4개 하단 탭 |

- 카드 제목 기본 2줄을 지향하되 실제로는 **의미가 잘리는 강제 생략 금지**. 긴 한글·글자 확대 시 높이가 늘어야 한다.
- 본문 최적 읽기 폭 약 66~72ch, 모바일 16px 미만 기본 본문 금지. 아빠 본문은 더 여유롭게.
- 브랜드를 글자 크기로만 표현하지 않는다. 내용 위계, 길이, 여백, 콘텐츠 사진 비율로 편집감을 만든다.
- 시스템 글자 200% 확대, 브라우저 확대, 한글 개행은 **G1 실화면 검사 전에는 검증됐다고 표시하지 않는다**.

## 4. 간격·그리드·표면 토큰

| 이름 | 설계 값 |
| --- | --- |
| spacing | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64px |
| mobile gutter | 320~359px: 16px; 360~767px: 20px |
| tablet+ gutter | 768px 이상: 32px |
| max reading width | 720px |
| max editorial width | 1120px |
| section gap | 모바일 32~40px, 데스크톱 48~64px |
| card padding | 16~20px, 히어로 20~24px |
| card corner | 기본 16px, 히어로 20px, 입력 필드 12px |
| dad hero image | 16:10 또는 설명형 카드에 이미지 작게 |
| daughter hero image | 모바일 4:5 / 3:4 사진 중심 |
| compact image | 아빠 4:3, 딸 1:1 또는 4:5 |
| touch target | 내부 제품 설계 최소 44×44px |
| bottom navigation | 60~68px 가시 높이 + safe-area-inset-bottom, 본문 하단 여백 별도 |

320px 화면에서는 좌우 16px을 제외한 **288px 콘텐츠 폭**을 기준으로 설계한다. 모바일 하단 4탭은 균등 분배하고, 아이콘+텍스트 모두 잘리지 않게 설정한다. 최소 타깃 44×44px 확보. 탭 라벨 확대 시 두 줄 및 유연한 높이를 허용하되 가로 스크롤이나 가려짐 금지.

| EmptyState | 간결한 준비 중·없음·오류 안내 | 실제 없는 데이터와 시연 미구현을 구별 |

### 상태 규격
- 기본 / 호버 / 누름 / 포커스 / 비활성 / 로딩 / 빈 상태 / 오류를 문서화한다.
- 키보드 포커스: **3px 고대비 외곽선, 2px offset** 설계안. 실제 배경별 대비·클리핑은 G1에서 검증.
- 비활성 기능은 이유를 명확히 안내하며, 클릭되는 것처럼 속이는 버튼 금지.
- 콘텐츠 등장 모션은 필요할 때만 120~180ms 내외, prefers-reduced-motion이면 제거. 스크롤 잠금·콘텐츠 늦은 표시·자동재생 금지.
- ‘공감’, ‘댓글’, ‘투표’ 등 데모 동작이 실제 반영되었다는 착시를 주지 않는다.

## 7. 사진·아이콘·외부 자산

- G0-03 와이어프레임에서는 **사진 자리 표시자만 사용**한다.
- G1 구현 시 공식 이미지·사용권/초상권이 확인된 사진, 허용된 임베드·원문 링크만 사용한다.
- 초상·학교·위치가 드러나는 청소년 사용자 업로드는 초기 제품에서 지원하지 않는다.
- 아이콘은 절제된 20~22px 선형이며 주요 메뉴에 반드시 텍스트를 붙인다. 이모지로 UI를 대체하지 않는다.
- 이미지 최적화와 대체 텍스트·지연 로딩·CLS 방지를 구현 단계에서 점검한다.

## 8. 접근성 및 검증의 경계

**문서 단계 검증:** 지정 색상 대비 계산, 배경/토큰·단위·사용 위치, 320px 콘텐츠 폭 산술, 4탭 구조, 중요 정보의 시각적 우선순위.

**G1 실구현 QA 필요:** 320/360/375/390/430/768/1024px 화면, iOS Safari·Android Chrome, 200% 텍스트 확대, 키보드·스크린리더, 시각적 회귀, 실제 사진의 대비, focus/hover/disabled, 이미지 로딩·alt, safe-area 겹침. axe는 수동 접근성 검사의 대체재가 아니다.

WCAG 2.2 AA에서 일반 본문 4.5:1 / 큰 글씨 3:1, 중요한 비텍스트 UI 상태·경계 3:1을 목표로 한다. 44px 타깃은 제품 **내부 기준**이지 WCAG AA의 모든 버튼에 적용되는 의무 최소치로 오해해서는 안 된다.
