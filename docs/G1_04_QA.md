## 남은 제한/미실시

- Chromium 반응형 시뮬레이션은 실제 iPhone Safari/Android Chrome 기기 검사가 아님. 실기기·수동 스크린리더/사용성·디자인 사진 품질 점검은 향후 별도 Gate에서 진행.
- 브리핑/질문/대화 연결 경로는 화면 이동 확인용으로 **준비 중 안내만** 표시. 트렌드 실제 상세/출처·날짜 검증은 G1-06 이전 미구현.
- 사용자별 글쓰기, 익명 게시판 운영, 개인 정보, 실서비스 SNS 수집, 세일 정보, 쿠키/분석, 유료 API, Auth/DB/RLS, 공개 배포 미도입.
- 문서상 딸 공간 디자인 변경은 G1-05 산출물의 **시각 방향 확정**일 뿐, 딸 홈 구현·접근성 QA를 수행한 것이 아님.
- 최종 PR HEAD의 CI 성공 여부 및 PR 병합 상태를 GitHub에서 재조회하여 확정한다.
