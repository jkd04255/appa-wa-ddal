## 기능·디자인 구현 내역

- W-03에 따라 딸 홈을 **겉으로는 깨끗한 취향 매거진, 안쪽은 은근한 언더그라운드 독립 잡지의 편집 리듬**으로 구축함. 밝은 크림 #FAF8F4, 차콜 #27242C, 절제된 베리 #774A61.
- 첫 화면 4:5 대형 사진형 히어로 1개, 관심사 3+전체 카테고리 링크, 사진형 발견 카드 3개, 합성 쇼핑 노트 2개, 샘플 커뮤니티 글 2개, 가상 주간 질문 1개, 서로의 시선 편집 카드 1개.
- 960px 이상에서 사진 카드가 살짝 어긋나는 매거진 리듬, 600px 미만 단일열, 모바일 하단 4탭, 안전 영역과 기존 skip-link/키보드 포커스 보존. 복잡한 팝업/자동재생/무한 캐러셀 없음.
- `src/domain/daughter-editorial.ts`와 `src/data/fixtures/daughter-home.ts`에 TypeScript literal demo 상태·읽기 전용 합성 fixture. 게시글 사용자·실응답·할인율/가격/시작일/종료일 조작 없음.
- 실제 동작하지 않는 세일/투표를 숨기지 않고 /daughter/sales, /daughter/polls를 **준비 중 페이지로 명시**. 상세 /daughter/discover/[slug]는 구현 전 404.
- G1-04 아빠 홈·G1-02 역할 선택/localStorage·G1-03 공통 4탭 코드 보존. 딸 페이지 자체에는 클라이언트 글쓰기·투표·DB/API/서버 저장 없음.
- 각 사진·발견·쇼핑·질문·관점에 '시연 콘텐츠' 표기. 커뮤니티 각 항목에 '샘플 게시글 · 실제 저장되지 않습니다'. 화면 하단에 상세 부가 설명 분리 배치.

## 자산 / 라이선스 검증

- 사진 4개는 Unsplash License가 적용된 각 사진 페이지를 확인한 후 GitHub Actions로 다운로드하고 `public/editorial/*.jpg`에 자체 호스팅.
- 최초 `unsplash.com/photos/.../download` 호출은 401로 실패, 사이트가 제공한 이미지 CDN 경로를 이용하도록 수정한 뒤 4개 모두 JPEG 검증 및 커밋 성공.
- 방문자의 제3자 추적을 방지하기 위해 앱 내 외부 CDN·외부 이미지 호출을 사용하지 않음. `next/image` + `alt` + 4:5 사진비 + 반응형 sizes 설정.
- 자세한 사진 출처/권리·초상권 주의: [G1_05_PHOTO_ASSETS.md](./G1_05_PHOTO_ASSETS.md). 해당 사진은 실제 상품·유행·커뮤니티에 대한 증거가 아님.
