# G1-10 운영자 작성 투표·토너먼트 시연 QA

> 상태: 구현 후 PR 자동 QA 대기. 합성 fixture와 React 메모리 상태만 사용하는 G1 정적 시제품입니다.
> G2-01·02·03 HOLD, 실서비스 기능 및 배포 금지를 유지합니다.

## 구현 범위

- 기존 딸 공간의 `/daughter/polls` 경로를 유지하고, 운영자가 미리 작성한 고정 선택지 질문을 표시합니다.
- 같은 페이지에 운영자 작성형 4개 항목 토너먼트를 추가합니다. 이용자는 준결승 2회와 결승에서 고정 보기만 선택하며, 개인 화면에만 우승 선택이 표시됩니다.
- 투표 선택과 토너먼트 진행은 컴포넌트의 React 메모리 상태에 한정합니다. 제출 폼·쓰기 API·저장소·쿠키·결과 숫자·전체 집계는 없습니다.
- 콘텐츠는 `src/data/fixtures/operator-activities.ts`의 정적 코드 fixture입니다. 운영자 CMS/Auth·관리자 UI·런타임 등록/수정은 만들지 않았습니다.
- 사용자 게시글·댓글·질문/보기 추가 기능을 제공하지 않습니다. 원래의 편집 화면과 가상 투표는 시연용 메모리 미리보기로 유지합니다.

## PR 검증 항목

자동화 CI에서 다음 항목을 검증하고, 실제 결과를 최종 커밋 기준으로 기록합니다.

- 기존 G1 회귀 및 `/daughter/polls` 접근성/반응형 QA
- 토너먼트가 3단계 선택 후 개인 우승 항목을 표시하고 초기화되는지
- 투표 및 토너먼트 선택 후 네트워크 쓰기, localStorage/sessionStorage, cookie, 응답 집계가 발생하지 않는지
- 320~1024px 레이아웃, 200% 글자 확대, axe 자동 접근성 검사
- lint, typecheck, Next build, HTTP smoke
