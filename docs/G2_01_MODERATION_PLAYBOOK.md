# G2-01 운영·신고·보호 대응 Playbook v0.1

상태: **시나리오 문서 초안 / 실제 신고 채널·운영 인력 없음 / 배포·개설 승인 아님**  
법률 기준: [G2-01 청소년 정책 검토](./G2_01_CHILD_SAFETY_POLICY_DRAFT.md)  
의사결정: [G2-01 결정·위험·Gate](./G2_01_DECISIONS_AND_RISKS.md)

## 1. 현재 실행 가능한 범위와 책임 소재

- G1은 **합성 콘텐츠만** 표시하며, 실제 커뮤니티 게시/신고 제출 API가 **없다**. '신고 접수 완료', '24시간 감시' 등의 표현은 거짓이므로 UI/약관에 추가하지 않는다.
- 실제 UGC를 열려면 **운영 주체/대표 책임자, 개인정보 담당, 콘텐츠 안전 책임자, 1·2차 검토자, 법률 자문 창구, 야간/휴일 긴급 대체 담당, 독립 감사자**를 서면 지정하고 호출 테스트를 남겨야 한다. 최소 한 사람이 모든 승인·비공개·복구 권한을 갖는 구조는 금지 후보.
- 담당자가 없거나 응답 SLA를 실현할 수 없다면 **게시 수집을 시작하지 않음**. 모니터링 가능 시간에만 게시 수집을 허용하는 제한형 운영을 미래에 검토할 수 있으나, 청소년 긴급사고는 운영시간 밖에도 발생하므로 그 위험의 법률/운영 승인 필수.
- 부모/청소년이라는 선택 화면은 계정 검증이 아니다. **실인증 전 역할 전용 UGC 읽기·쓰기·신고의 공개 자체 금지**.

## 2. 게시물 사전 검수 (미실행 설계)

1. **모든 신규 UGC, 댓글, 이미지·링크가 있다면 모두 '비공개 검수 대기'**를 기본값으로 둔다. DM·1:1 채팅·사용자 검색/프로필·사진·위치·연락처 교환은 허용 후보에서 제외.
2. 검수 전 PII·외부 연락 경로(휴대전화·SNS ID·학교·반/학년·구체 위치·실명·사진/특이 사건) 위험을 확인하되, 필터의 오탐/우회 가능성을 명시. AI 분류만으로 자동 공개 금지.
3. 아래 심각도별 우선 처리 경로로 이관. 현 단계에서 실제 개인정보/증거를 저장하지 않는다. 장래에도 모더레이터 최소권한/열람기록/유출 예방이 전제.
4. 승인·반려·가림·수정 요청·복원 이력을 검수자/검토자/사유로 남기는 방안은 **향후 G2 기술 설계 후보**일 뿐 현 단계 구현하지 않음.
5. 작성자가 입력하기 전에 일반적인 주의문을 배치: "이름, 연락처, SNS 아이디, 학교, 위치, 민감한 사연, 다른 사람의 정보를 적지 마세요." 실서비스에서는 요청/삭제 등 법정 절차도 설명.

## 3. 사건 분류·에스컬레이션 표 (운영상 제안 목표, 법정 기한이 아님)

| 우선순위 | 예시 | 사전 승인된 운영 주체의 권장 조치 | 목표·한계 |
| --- | --- | --- | --- |
| **P0 긴급** | 미성년자 대상 성적 접근/협박, 성착취 의심, 구체적 자해·타해/실종·즉각 위험, 아동 개인정보 대량 노출 | **공개 전 차단·격리** 우선. 실제로 생명/안전상 위험이면 지체 없이 관할 기관 신고·협조 검토(긴급 112/119). 접근권 제한된 전문 처리자에게 즉시 이관. 불법 자료는 임의 복제/공유하지 않음 | **발견 즉시**가 운영 목표. 실질적 24/7 대기·연락 체계와 담당자가 없으면 서비스 개설 금지. 무조건적 처리시간 보증 아님 |
| **P1 높음** | 신상정보 게시, 반복적인 스토킹·외부 SNS 이동 유도, 특정인 괴롭힘/갈취, 자살 신호의 불명확성 | 우선 비공개, 위험/재확인 조사, 당사자 안전 고지 및 보호 담당자 배정, 전문가 판단 필요 시 기관 연계 | 내부 제안 **접수 후 1시간 이내 1차 검토** 목표. 가동률·인력 증명 전 약속/약관에 표기 금지 |
| **P2 중간** | 명예훼손 의심, 사생활 침해·저작권/개인 신원 단서, 비동의 원문 공유 | 임시 비공개·권리침해 소명/절차 확인, 정보통신망법 제44조의2 등 법적 절차 적용 여부 검토, 통지·복원/불복 | 내부 제안 **운영일 1일 내 1차 검토**, 법률 '지체 없이' 의무의 대체가 아님 |
| **P3 낮음** | 주제 이탈, 공격적 표현·비정치적 논쟁·스팸 | 게시 거절/보류 및 안내·이의제기, 운영 통계만 | 내부 제안 **운영일 3일 내**. 확정 전 미공개 |

**중요:** 위 시간은 법정 의무가 아니라 **아직 채택되지 않은 자체 서비스 목표 후보**다. 법이 요구하는 '지체 없이' 조치/법정 통지·신고는 이 목표보다 우선한다. 인력/시스템을 갖추기 전 서비스에서 "24시간 응답 보장" 문구 사용 금지.

## 4. 권리침해·신고·이의제기 처리 (시나리오)

- 접수 설계안: 신고 대상·유형·위험도·필요 최소 설명·응답 통지 수단. **정확한 URL/시간, 신상 단서, 신고자 식별정보를 불필요하게 더 수집하지 않음**. 미성년자의 신원을 공개된 양쪽 커뮤니티에 나타내지 않음.
- **실제 접수 기능은 아직 없음.** 신고 양식/접수 완료 알림/사건 번호/데이터베이스/메일 자동 발송을 개발하거나 작동 중이라고 설명하지 않는다.
- **권리침해 요청:** 정보통신망법 제44조의2 적용 여부/절차 확인. 사생활 침해·명예훼손 정보 삭제/임시조치 등과 신청인·게시자 통지. 법률상 다툼이 예상되는 **임시조치 기간 30일 이내**는 일괄 보존 기간이나 모든 신고 처리시간이 아님.
- **이의신청:** 원 게시자/신고자에게 통지 가능한 범위와 반론·복원 절차를 분리. '이의 신청 = 무조건 복원' 금지, 특히 아동 안전 위험 시 복원 전 재심사.
- **위기 상황:** 112(긴급 범죄), 119(응급/화재·구조), 117(학교폭력 상담·신고), 1388(청소년 상담)은 행정안전부 긴급신고 체계 자료로 확인. 이 연락 수단은 **운영자가 직접 제공하는 구조 서비스가 아니며**, 위급 시 플랫폼만 믿고 기다리지 않도록 안내.
- **성착취 관련 증거:** 민감·불법 영상·신상정보의 자의적 수집/복제, 외부 번역/LLM 전송, 일반 업무용 메신저 전파를 금지할 후보 정책. 정당한 법률상 보존·신고·요청 대응은 전문 기관/변호사와 사전 설계하고 최소 권한/기록·보존 책임을 지정.
- **정정/삭제:** 공개 상태와 서버 저장 상태의 동시 조치, 검색 인덱스·링크 미리보기·백업/캐시 전파, 감사 증적/법적 예외 분리. 상세 파기·보존 기한은 데이터 항목별 법적 근거 확인 전 **미정**.

## 5. 최소 운영 절차 및 체크리스트 (인력·교육·사고)

- **계정 권한:** 일반 모더레이터는 자기 담당 큐만 열람, 아동 관련 심각 사건은 훈련받은 보호 책임자만 접근, 사전 공개/복원은 2인 승인 후보.
- **교육:** 개인정보 취급·그루밍 징후·아동 안전·반복학대/사이버폭력·편향된 제재·신고자 보호·우발적 접촉 대응·증거 훼손 금지·유출/사건 핸드오프.
- **민감 컨텐츠 검토자 보호:** 반복 노출/교대/휴식/전문 지원/최소 노출 원칙과 작업도구 보호 설계.
- **분리:** 원문/댓글, 신고/증거, 계정/동의, 공용 합성 편집글을 각각 권한·보유기간·공개 모델로 분리; 직원도 원칙적 최소 접근.
- **사고 훈련:** 모의 신고 접수·권리침해 삭제/통지, 긴급 담당자 부재/교대, 계정 침해·개인정보 유출등 통지/신고, 데이터 삭제·백업 복원, 공용 사연 재식별의 긴급 내림을 테이블탑 모의훈련으로 실시. **실제 미성년자의 사례·정보를 훈련자료로 사용하지 않음**.
- **운영자 감사:** 오탐·억울한 제재/복구, 처리 지연, 개인별 예외 승인, 신고 중단/반려, 유출 위험을 주기적으로 점검. 허위 인기/투표/가입자 수 생성 금지.
- **서비스 중단 기준:** 긴급 담당 부재, 누적 미검수 건 폭증, 권한 우회, 민감 자료 유출, 신고 채널 장애, 실시간 검수 불가능, 보호자 동의 확인 실패가 발생하면 신규 UGC를 **차단**하는 fail-closed 계획 채택 필요.

## 6. 인력과 비용: 공개 견적이 아닌 가정식

**작업량 산식(모두 추정/내부 기획용):**

- 검수시간(시간/일) = 일일 신규 본문·댓글 수 × 평균 심사 분 / 60 + 신고 검토 건수 × 평균 처리 분 / 60 + 이의신청/재검토 + 정책/교육 + 사고 대응.
- **가정 시나리오 S1:** 신규 항목 하루 100개, 항목당 3분이면 **5시간/일**. 신고/이의신청/휴일/야간·2인 승인/교육은 **추가**. 단독 담당자로 24시간 상시 대응할 수 없으며, 휴가·병가·식사도 별도 계산.
- **가정 시나리오 S2:** 하루 1,000개 × 3분 = **50시간/일**로 기본 검수만 최소 여러 인력·교대가 필요. 신고나 P0 대응, 관리자 결재 시간 미포함.
- 비용(월) = (검수 작업시간 × 실제 인건비 시급) + 책임자/야간대기/교육·법률 자문 + 인증/위탁·시스템/감사/보안 + 사용자 지원/신고/재심사 + 리스크 준비금. **현재 가격 인용·업체 계약·실제 예산 승인 없음**.
- 지원 구조 없이는 **콘텐츠량이 적어도 P0 사건의 빈도가 불규칙**하므로 당직·대체 인력·전문가 연락 체계가 필요. 조직이 작은 초기 단계에서는 **A안: 실사용자 커뮤니티를 열지 않고 편집 매거진만 운영**이 인력·안전 관점에서 우선.
