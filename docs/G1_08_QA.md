## 구현 범위

- `/dad/perspectives` / `/daughter/perspectives`: 아빠·딸 각자의 시각적 디자인을 가진 서로의 시선 **합성 목록 3개**. 공용 fixture `SHARED_PERSPECTIVES`에서 **동일한 3개 독립 편집 ID·제목·문장**만 읽기 전용으로 노출.
- `/dad/perspectives/[slug]` / `/daughter/perspectives/[slug]`: 정확히 3개씩 상세 연결. 양 공간에서 같은 slug는 같은 두 가상 관점, 가상 맥락과 부담 없는 질문을 출력. 역할·다른 ID·없는 slug는 404. 홈/4탭/두 커뮤니티/9개 G1-06 에디토리얼 상세 보존.
- `/daughter/polls` 및 양 공간의 서로의 시선 목록: 선택지 3개로 **가상 보기 선택** 체험. 결과 숫자, 백분율, 실제 응답 수, 통계, 실사용자 입력 수집·서버 요청 없음. React 메모리에서 radio 선택과 선택 지우기만 작동하고, 새로고침/공간 전환 시 폐기. 설문 제출·저장/동의·완료라고 표시하지 않음.
- 아빠 스타일은 아이보리·딥 블루그레이, 딸은 크림·차콜·절제된 베리 **Polished Underground** 유지. 모바일 단일열, 충분한 클릭/라디오 터치 크기, 키보드·스크린리더 labels, reduced motion 및 200% 글자 확대 고려.
- 에디토리얼 글과 설문은 **실제 커뮤니티 데이터에서 추출하지 않은 독립 수작업 합성 글**. `src/data/fixtures/shared-perspectives.ts`와 `src/domain/perspective-editorial.ts`에는 원문 게시글 ID·댓글·계정/작성자 ID·인용·신원/나이·구체 위치·민감 사연·표본 크기/인구통계·응답 수/유저 투표가 없음. 도메인 모델에서도 해당 필드를 제공하지 않음.
- UI의 정보보호 고지: **시연 콘텐츠 · 원문 없음 · 확인일 해당 없음 / 가상 설문이며 실제 투표·통계가 아님**. 특정 가족·연령·성별을 대표하는 실증 결과처럼 묘사하지 않음.
- **G1에서는 실제 사용자의 타 공간 원문을 공유할 수 없음**. 향후 G2의 동의·법률·재식별 방지·권한/운영 정책이 충족되지 않으면 실데이터 기반 기능을 열지 않음.
