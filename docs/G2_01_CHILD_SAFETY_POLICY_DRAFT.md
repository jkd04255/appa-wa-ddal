## 3. 연령 적격·동의·역할 검증 정책 후보

- **지금**: 아빠/딸 화면 버튼, localStorage 한 개의 최근 탐색 공간, 모든 글과 투표는 합성 데이터. 누구나 두 공간을 열어 볼 수 있어야 하며 '검증된 회원' 문구 금지.
- **만 14세 미만**: 개인정보 처리에 동의가 필요한 경우 법정대리인 동의·확인을 법률상 검토. 서비스 자체가 14세 이상으로 제한될 경우에도 **연령 허위 입력·우회·실수 가입·신고 시 처리**가 필요하며 자기신고 버튼만으로 충족되었다고 판단하지 않는다.
- **만 14세 이상 19세 미만**: 만 14세 미만의 특칙을 전부 적용한다고 단정하지 않되 **청소년 보호 설계는 계속 필요**. 개인정보/사연 공개 기본 비활성, 위치·외부 연락 방지, 쉽게 읽히는 안내/권리 보장, 사전 검수.
- **성인 '아빠' 검증**: 성인 인증(나이) != 아버지/법정대리인/해당 딸의 부모 증명. 가족관계증명서·주민등록번호·학교/신분증 원본 **프로젝트에서 직접 수집하지 않음**. 역할 특권을 부여하려면 법률 자문과 개인정보 침해가 낮은 제3자 증명 수단의 계약/평가가 필요.
- **'딸' 검증**: 성별·미성년 여부·가족관계 검증 방법 미정. 성별을 증명하도록 강제하거나 공개 프로필에 표시하는 방안은 **권고하지 않음**. 안전 대안은 **실제 역할별 쓰기 기능 자체를 도입하지 않는 것**.
- **제3자 검증 옵션**(미채택): 인증 결과의 필요 최소 주장(예: 성인 여부/연령대/검증 유효기간)만 수용하고 원본 신분정보는 서비스에 전송하지 않는 모델을 법률·위탁·국외이전 관점에서 평가. 기술 공급업체, 비용, 보관, 오류·이의신청, 부모-자녀 관계 진위는 미확정.
- 법정대리인 동의와 공용 '서로의 시선' 외부 공개 동의는 **목적이 다른 별도 절차**. 일반 서비스 약관을 누르면 사연의 반대 공간 공개에 자동 동의하는 식의 묶음 동의/사전 체크는 금지할 설계 후보.

### 4.2 처리원칙 제안 (확정 전 기본 거부)

1. 항목마다 목적·처리 법적 근거·담당자·필요성·대체 수단·최소 보유 기간을 작성하고 필요 없는 이름/학교/학년/정확한 생일/위치/얼굴/전화·SNS 계정/민감 사연은 **수집하지 않는다**.
2. 생성 게시물과 신고자료는 성격과 보존 목적이 다르므로 저장소·권한·삭제 절차를 분리한다. 전처리 본문, AI 분류 결과, 검색 색인, 캐시, 백업도 파기 대상에 포함한다. 디지털 증거 보존이 필요한 경우 법률 근거·범위/기한·담당자·감사 로그에 따라 제한하고 남용 금지.
3. 열람·정정·삭제·처리정지·동의 철회 및 법정대리인 권리 요청을 수용할 운영 수단/본인확인 방식을 사전 설계한다. **익명 닉네임이라고 실제 개인정보가 없는 것이 아님**. 이메일/계정 ID가 없어도 내용과 맥락으로 특정 개인 식별 가능.
4. 개인정보 처리방침/약관·위탁/제3자 제공/해외 이전 현황, 아동에 쉬운 언어와 독립적 동의 UI를 법률 전문가가 승인하기 전 실제 서비스 수집 금지.
5. 해시·가명처리·소표본 임계치만으로 완전 익명성 보장이라고 주장하지 않는다. 학교/지역/시간/상황·검색어 조합으로 식별될 수 있으므로 위험 평가 없이 집계·편집글 배포하지 않는다.
6. 사고 대응·유출등 통지/신고 의무, 권리침해 게시물의 삭제·임시조치 및 알림 절차는 법령·시행령·기관 지침/계약상 요건을 포함한 전문 검토 필요. **이 문서에서 법정 기한을 임의 설정하지 않음**.

## 5. 교차 공간 공개의 원칙 (매우 중요)

- 두 커뮤니티 게시글/댓글/신고/신원·신고자/법정대리인 여부 등 원문은 **서로 다른 보호 도메인**. 아빠 화면을 누른 이용자가 딸 게시물 원문을 읽을 수 있는 설계를 만들지 않는다.
- 지금은 완전히 별개인 합성 편집 문장만 양쪽에 제공한다. 이후에도 원문의 그대로/거의 그대로 인용, 희귀 사연·학교·학년·특정 사건·댓글 원문, 원문 URL/slug/ID, 소규모 통계의 공개를 **기본 거부**한다.
- 동의가 있더라도 독립적인 아동/청소년 보호 검토와 문맥 추적·검색 재식별 위험 심사, 편집자 이중 승인, 철회·수정/캐시 삭제 절차가 필요. 공개에 적합하다고 검증되지 않으면 **아예 게재하지 않는다**.
- **공개 기준 k값이나 최소 응답 수 미결정:** 숫자를 임의로 정해 안전하다고 주장하지 않는다. 개인별 특이성이 높으면 충분한 집계 숫자가 있어도 공개 거부. 실제 사용자 원문 기반 집계는 G2/G3 승인 전 차단.

## 6. 금지선과 법률 자문 요청

**절대 금지 (G2 HOLD):** Auth/DB/RLS/실사용자 계정·글/댓글/신고·투표/집계, 개인정보/로그 서버 저장, 위치·DM·사진 업로드, 유료 API·무단 SNS 수집, 광고 추적, 실서비스 공개 배포. 이 문서 작성으로 기능 개발을 승인했다고 보지 않는다.

**법률 자문 필수:** 개인정보 처리 근거 및 동의/법정대리인 확인·연령 검증의 적법성, 14~18세 이용자 안내, 아버지/딸의 실질 역할 검증과 차별/과잉수집 위험, 정보통신망법상 게시물 삭제·임시조치·통지/이의신청, 아동 성착취 신고/증거 보전/법집행 협조, 개인정보 유출등 신고·권리 요청·보존/삭제, 운영주체 및 통신사업 관련 신고/책임 범위, 위탁/국외이전, 광고/수익화.

**승인권:** 개발자 한 사람의 낙관적 판단으로 통과할 수 없다. 실제 운영자(안전·신고 책임), 개인정보 보호 담당, 법률 검토자, 보안 검토자의 의견과 증거를 기록하고, 결정 책임자가 별도 명시적 승인하기 전 **HOLD 유지**.
