## 3. Gate 통과 기준 (전체 현재 BLOCKED/HOLD)

### G2-01 — 아동·청소년 법률·운영 정책 (현재 HOLD)

통과 증거로 다음을 **모두** 요구한다.

- [ ] 정확한 운영·게시 기능, 이용자 연령 범위·지역·서비스 제공자의 법적 지위 확정
- [ ] 만 14세 미만 처리 여부/법정대리인 동의·확인, 14~18세 보호, 청소년 보호법과 다른 기준을 법률 전문가가 별도 검토
- [ ] 역할별 게시/읽기 권한을 실질 확인 가능한지 기술/법률/개인정보 전문가 평가. 불가능하면 해당 기능 **범위에서 제거**하는 설계 채택
- [ ] 개인정보 항목·처리 근거·동의 UI·처리방침/약관·보유/삭제/권리행사·위탁/국외 이전 검토 승인
- [ ] 게시물 사전검수·신고·차단·임시조치/통지·이의제기·수정/파기 SOP와 실제 운영 책임·휴일/야간·대체 인력 명시
- [ ] P0 긴급 대응·성착취/그루밍·폭력·피해보호 사례에 대한 외부 법률/전문기관 대응 계획과 인력 실습 완료
- [ ] 교차 공개 데이터 경계, 소표본/인용 재식별 방지, 원문 파생 콘텐츠 미개설 원칙 명문화
- [ ] 운영비·법률/개인정보/보안 예산, 사건량 초과 시 신규 UGC를 차단하는 중단 정책 승인
- [ ] 외부 자문 의견·미해결 위험·책임자 서명을 포함한 변경 관리 기록
- [ ] 사용자/승인권자의 **명시적 Gate 전환 승인**. 정책 문서 PR 병합만으로 게이트 자동 변경 불가

### G2-02 — 인증·권한·서버/DB 보안 (현재 HOLD)

선행조건은 **G2-01 별도 승인 완료**다. 이후에야 서명된 서버 주장 기반 인증, 사용자 권한/연령 정책의 정당성, 서버 API 권한·기본 거부, RLS 거부/타 공간 원문 접근/단축 URL·토큰 변조·직접 네트워크 우회, 비밀키 관리, 데이터 권한/삭제/감사 검증을 설계·구현할 수 있다. **현재 기술 작업 시작 금지.**

### G2-03 — 폐쇄형 실제 커뮤니티 시험 (현재 HOLD)

G2-01과 G2-02의 증거/독립 승인이 모두 선행하고 사전 검수·P0 비상대응·신고/이의제기/권리행사/삭제·모니터링의 무인 시간 대응이 실제 리허설로 확인돼야 한다. 이후에도 실제 회원/글 생성·운영/배포는 **별도 권한과 별도 출시 승인** 전 금지.

### G1 잔여 검증 (별도 필수, G2 승인 대체 아님)

iPhone Safari/Android 실제 기기 및 VoiceOver/TalkBack 수동 검사와 화면 스크린샷 감리는 **미실시** 상태. G1-09 Chromium 75/75 및 axe 통과는 이를 대신하지 않는다.

## 4. 다음 단계에 요구할 자료와 질문 (실제 구현이 아닌 문서 검토)

**사용자/사업 책임자 선택이 필요한 항목:** 실제 커뮤니티가 필수인가(대안 A 편집형과 비교)? 예상 일일 글·댓글/신고 수와 운영 가능 시간/예산은 얼마인가? 청소년 이용자 최소 연령/부모 역할 검증을 **어떤 법적 근거로** 입증할 것인가? 제휴 기관/전문 신고·모더레이션 인력 계약이 있는가? 운영 주체/법률 자문 담당을 누가 맡는가?

**현재 제공되지 않은 자료:** 사업자 등록·운영 주체, 이용약관/개인정보 처리방침, 연령/법정대리인 확인 공급자 및 법률 의견, SNS 데이터 이용 허락, 실제 청소년 신고 대응 계약/인력·예산, 이용자 권리 행사 시스템, 실기기 보조기술 수동 QA 근거. 없는 자료는 **확인 완료로 표시하지 않음**.

**제품 방향:** 초기 사용자 대상은 개인 게시 없는 편집형 콘텐츠입니다. 커뮤니티는 구체적인 참여 수요가 있어도 자동 개설하지 않으며, 안전·법률·개인정보·운영 역량/예산 검토와 G2 Gate 증거 및 별도 명시 승인을 거쳐 다시 결정합니다. 커뮤니티를 도입하지 않는 선택도 유지합니다. G2-01~03은 계속 HOLD, 실서비스 기능·배포 없음.
