## 정적 배포 설계

- `.openai/hosting.json`은 소유자 전용 Site ID와 `out`을 지정한다. 실제 배포 성공 전 예상 URL은 완료 증거가 아니다.
- `npm run build`는 기존 SSR 동작 유지. `npm run build:demo`는 `STATIC_DEMO=1`로 정적 내보내기를 수행한다.
- 검색 매개변수 두 곳(`/` 재선택, `/daughter/discover` 필터)은 정적 빌드에서만 Suspense 안 Client Component가 처리한다. 일반 빌드에서는 기존 서버 쿼리 렌더링 유지. 정적 빌드의 JavaScript 비활성 발견 목록은 전체 콘텐츠를 보여주며 필터는 JS 필요.
- 사진은 동일한 로컬 4개 JPEG. 정적 빌드는 이미지 최적화 서버를 필요로 하지 않는다.
- 배포에는 `out`의 정적 산출물만 포함된다. 문서, 테스트, 비밀 환경변수, DB/Auth/서버 쓰기 API는 서비스 경로로 공개하지 않는다. 검색엔진에는 noindex/nofollow를 선언한다.
- 초기 Site는 소유자 계정만 접근한다. 저장소 공개 변경이나 G2 운영 승인은 없다.
